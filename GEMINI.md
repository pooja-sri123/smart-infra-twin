# Smart Infrastructure Digital Twin

## Project Goal
Build an AI-powered Digital Twin platform for monitoring bridges
and infrastructure using IoT sensor data, AI anomaly detection,
risk prediction, and predictive maintenance.

## Architecture

Frontend:
- React
- Three.js
- Tailwind CSS
- Chart.js

Backend:
- Python
- FastAPI
- Uvicorn

AI:
- Isolation Forest
- Random Forest
- RUL prediction
- Explainable AI

## Rules

1. Do not break existing working functionality.
2. Do not replace the existing UI unnecessarily.
3. Test backend APIs after modifications.
4. Keep frontend and backend compatible.
5. Use realistic infrastructure terminology.
6. Preserve the existing Digital Twin dashboard.
7. Before modifying files, inspect the existing implementation.
8. When fixing an error, identify the root cause first.
9. Do not delete working features.
10. Keep code production-ready and hackathon-demo ready.
